FAMILIAI — VERSION WEB MOBILE

IMPORTANT : Android ne permet pas d'installer un fichier HTML local comme une PWA complète directement depuis le gestionnaire de fichiers.
Pour avoir l'icône FamiliAI sur le Samsung :
1. Héberge ce dossier sur un site HTTPS (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Ouvre l'adresse dans Chrome sur le Samsung.
3. Menu ⋮ > Ajouter à l'écran d'accueil / Installer l'application.
4. FamiliAI apparaîtra alors comme une application.

Pour un test immédiat sans hébergement :
- décompresse le ZIP sur le PC
- ouvre index.html dans Chrome
- tu peux ensuite l'héberger gratuitement pour l'installer sur le téléphone.

Cette version est un prototype fonctionnel : données locales, pas de compte ni de vraie IA connectée.
